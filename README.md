# news-pickup

Claude Code の定期実行ルーティンが自動生成するニュースアーカイブ。

| 種別 | 生成タイミング (JST) | 出力先 |
|---|---|---|
| 日次ピックアップ | 毎日 07:00 | daily/YYYY/MM/YYYY-MM-DD.md |
| 週間まとめ | 日曜 07:00 | weekly/YYYY-Www.md |
| 月間まとめ | 毎月1日 09:00 | monthly/YYYY-MM.md |

複数ソースを突き合わせ、論調が割れた点は断定せず争点として併記する方針。芸能ゴシップ・SNSの反応・未確認速報は収録しない。
